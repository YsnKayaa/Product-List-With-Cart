# Sepetli Ürün Listesi (Product List with Cart)
Sepetli tatlı listesi uygulaması. Düz HTML, CSS ve JavaScript kullanıldı. Kurulum veya derleme gerektirmez.

## Özellikler

- Ürünü sepete ekleme, adedini artırma ve azaltma (adet 0 olunca ürün sepetten çıkar)
- Sepetten ürün silme, toplam adet ve sipariş toplamı
- Fiyatlar Türk lirası (₺) cinsinden (tasarımdaki dolar fiyatları 1 $ = 50 TL ile çevrildi, `js/data.js` içinden değiştirilebilir)
- "Siparişi onaylamak istiyor musunuz?" sorusu (Evet / Vazgeç), ardından sipariş onay modalı ve "Yeni Sipariş Başlat" ile sepeti sıfırlama
- **Türkçe / İngilizce dil seçeneği** (küre ikonlu buton)
- **Açık / koyu tema** (ay ve güneş ikonlu buton; ilk açılışta sistem temasını kullanır)
- Sepet, dil ve tema tercihi tarayıcıda saklanır, sayfa yenilenince kaybolmaz
- Mobil, tablet ve masaüstü için duyarlı tasarım
- Klavyeyle kullanım ve ekran okuyucu desteği (odak yönetimi, ARIA etiketleri, ESC ile modal kapatma)
